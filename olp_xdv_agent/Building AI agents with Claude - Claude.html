The pattern you saw, precisely:

Every app in this space (ExPrysm, TopStreaks, OliveOdds, BetSeek, OddsFlow) uses the same three numbers, side by side:

  1. Model % — what the AI's own probability model calculates
  2. Market/Bookmaker % — the bookmaker's odds converted to an implied probability (odds of 2.10 → 1÷2.10 = 47.6%) ExPrysm
  3. Edge — Model % minus Market %. A positive edge gets flagged as a value bet ExPrysm

So "64% chance, bookmaker 47%, edge 9%"-type numbers you saw are literally that formula — one app even states the rule outright: a value bet is flagged when model probability is at least 5 percentage points higher than the bookmaker's implied probability. TopStreaks

The genuinely good news for you: your framework already computes this exact math. HR30's MES is doing the same comparison — you just haven't been displaying it as its own headline number the way these apps do.
